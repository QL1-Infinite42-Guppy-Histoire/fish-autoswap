Before you start / 始める前に

  • This page deploys the FishAutoSwap contract. The deploying wallet becomes the contract owner (it can only set the keeper and pause — it can never touch user funds).
  • Deployment costs a small amount of [42] in gas. Make sure the wallet is on 42 Chain (421018).
  • Never enter a seed phrase or private key anywhere — this page never asks for one. デプロイはウォレットの署名だけで行います。

We only read your public address until you press Deploy.
